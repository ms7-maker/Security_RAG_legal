1. Маркеры безопасности

Ограничения на схеме доступа юрфирмы

🔒 Маскирование PII

БД_3 · Подписанные договоры

ФИО клиента, ИНН, банковские реквизиты не уходят в LLM в открытом виде — заменяются на [Client], [INN], [Account].

🔑 Доступ по ID дела

БД_3 · Отдел договоров

Нельзя запросить «все договоры». Доступ только к файлу/карточке с явным номером дела или ID контракта в текущем запросе.

🔑 MFA

Переход к БД_3 и БД_4

Договоры и внутренние справочники требуют дополнительного подтверждения (OTP / токен / согласие с регламентом).

📝 Журнал изменений

БД_4 · Сотрудники и клиенты

Любая правка партнёра пишется в неудаляемый лог (только добавление записей, стереть историю нельзя).

📋

2. Правила доступа

Смысловая логика Legal RAG Assist

Правило А: Своя практика

Юрист-консультант работает только со своей отраслью (адм. / трудовое / корпоративное / налоговое). Чужие практики и весь архив договоров в ответе не появляются.

Правило Б: Контракт → отдел договоров

После подготовки контракт уходит в изолированный контур БД_3. Консультанты практик туда не входят. Отдел договоров видит документ по ID дела; партнёр — для контроля.

🎯

3. Цели системных промптов

Поведение ИИ в зависимости от роли

🎯 Консультант (практика)

  • Ответы только по своей отрасли и общим материалам.
  • Запрет на выдачу чужой практики и архива договоров.
  • Вежливый отказ при попытке выйти за периметр роли.

🎯 Отдел договоров

  • Работа только с договором / делом по явному ID.
  • Запрет сквозного листинга и «всех контрактов».
  • Маскирование реквизитов клиента перед ответом.

🎯 Партнёр

  • Сквозной просмотр практик и договоров для контроля качества.
  • Правки справочников (сотрудники / клиенты) с обязательной записью в журнал.
  • Не разглашать внутреннюю структуру логов клиентам во внешних ответах.

Индикаторы Security_RAG_legal

🔒 PII

Реквизиты клиента маскируются перед LLM.

🔑 ID / MFA

Договоры — по номеру дела; MFA на БД_3 и БД_4.

📝 Лог

Правки справочников пишутся навсегда.

👁️‍🗨️ Симуляция

Выберите роль сверху — недоступные блоки погаснут.
